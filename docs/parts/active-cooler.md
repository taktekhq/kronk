# Raspberry Pi 5 Active Cooler

Official cooler for the Pi 5. Aluminum heatsink with a temperature-controlled blower fan. Push-pin mount, thermal pads pre-applied.

## Specs

- Input: 5V DC via the Pi 5 four-pin fan header
- Fan control: PWM with tachometer feedback
- Max airflow: 1.09 CFM
- Max fan speed: 8000 RPM, plus or minus 15%
- Material: anodized aluminum
- Mount: spring-loaded push pins
- Pi 5 only
