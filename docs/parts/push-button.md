# Metal Push Button, Momentary, 12mm, LED Ring

Stainless steel waterproof push button with a 12V LED ring. Used as the doorbell.

## Specs

- Type: momentary, push to activate, release to reset
- Rating: 36V 2A
- LED voltage: 12V
- Mounting hole: 12mm
- Total length: 21.3mm, head width 14mm
- LED colors available: white, yellow, pink, blue
- Material: stainless steel, silver finish
- Mount: rubber ring plus hex nut, dust and waterproof
- Contacts: silver-plated copper
