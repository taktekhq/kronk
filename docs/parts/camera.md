# Raspberry Pi Camera Module 3 NoIR

12MP camera with a Sony IMX708 sensor and no IR cut filter, so it sees in low light and infrared. Fast autofocus.

## Specs

- 12MP Sony IMX708 back-illuminated stacked CMOS sensor
- High signal-to-noise ratio
- 2D Dynamic Defect Pixel Correction (DPC)
- Phase Detection Autofocus (PDAF)
- QBC Re-mosaic function
- HDR mode up to 3MP output
- Resolution: 4608 x 2592 (11.9MP effective)
- Sensor size: 7.4mm diagonal, pixel size 1.4um x 1.4um
- Diagonal field of view: 75 degrees
- Video modes: 1080p50, 720p100, 480p120
- RAW10 output
- No IR cut filter (NoIR variant)
- CSI-2 data output, I2C fast mode control
- 2-wire serial control for autofocus
- Dimensions: 25 x 24 x 11.5mm
- 200mm ribbon cable, 15 x 1mm FPC connector
