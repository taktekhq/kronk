# Relay 1 Channel 5V

5V relay module with TTL control input. Switches DC or AC loads up to 220V AC.

## Specs

- Control: 5V TTL signal
- Contacts: one normally open, one normally closed
- Power indicator LED and control indicator LED
- Transistor-driven coil, high impedance control pin
- Pull-down on the control pin to prevent false triggering when floating
