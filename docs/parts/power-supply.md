# Raspberry Pi 27W USB-C Power Supply (EU)

Official USB-C PD adapter for the Raspberry Pi 5. Delivers 5V 5A, which unlocks higher USB current for accessories on the Pi 5. Model ELE-DEB-RAA-041.

## Specs

- Total power: 27W
- Input: 100V to 240V AC
- Output profiles: 5V 5A, 9V 3A, 12V 2.25A, 15V 1.8A
- Connector: USB Type-C
- Plug: EU
- Cable: 1.2m, 17 AWG
- Color: white
